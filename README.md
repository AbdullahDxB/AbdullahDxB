## Featured Projects

### [CAN Bus MCP2518 Transceiver Board](https://github.com/AbdullahDxB/CAN-PCB)
Designed and routed a two-layer CAN bus transceiver node optimized for high-integrity industrial communication.
* **Focus:** PCB Layout, Differential Pair Routing, DRC Validation, Manufacturing File Generation.
* **Tech:** KiCAD, CAN Protocol, Hardware Prototyping.

### [Custom PIC-Based Telemetry & Sensor Board](https://github.com/AbdullahDxB/PIC-Telemetry-PCB) 
Developed a custom hardware platform featuring a DC-DC buck converter and real-time kinetic sensing.
* **Focus:** Schematic Capture, Power Electronics, Firmware Debugging, I2C/SPI Interfacing.
* **Tech:** Altium Designer, PIC Microcontroller, Embedded C.

### [STM32-Based Audio Equalizer](https://github.com/AbdullahDxB/ARM-Audio-Equalizer)
Real-time 3-band audio equalization leveraging an ARM Cortex-M architecture.
* **Focus:** DMA (Direct Memory Access), ISRs, IIR Biquad filter implementation.
* **Tech:** STM32, Embedded C, Keil µVision.

### ESP32-S3 Edge Cardiovascular Detection (Internship)
Engineered an edge-computing ECG system focusing on low-latency sensor execution.
* **Focus:** Hardware Integration, Bare-metal execution, Quantized Model Deployment.
* **Tech:** ESP32-S3, C/C++, TinyML.
